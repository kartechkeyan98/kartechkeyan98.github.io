Convolutional Neural Network (CNN)

This family of Neural Networks are specifically designed to operator on images with channels.

Hence, the input space X= Rci​×hi​×wi​, where i subscript here will stand for input image related attributes.

The output space will depend on the tasks, some common ones being covered in the last section.

The core novelty in this chapter is the convolution layer, which takes in a channeled image and outputs another channeled image, i.e. X= Rci​×hi​×wi​ and Y =Rco​×ho​×wo​ where the o subscript stands for output attributes.

The dual of that is the Transposed convolution Layer which is actually the adjoint operator of the original conv2D operation.

2.1 Building Blocks of core CNN

This section deals with convolution layer and its variants. In short, the convolution layer family is an image-to-image type of layer. Hence, X= Rci​×hi​×wi​ and Y =Rco​×ho​×wo​.

2.1 Base Operations in CNN

The two basic operations in CNN are: cross-correlation and transposed convolution

Definition 1.1 [Cross-Correlation; Transposed Convolution]

1. [Cross Correlation]
Given an image X∈Rh×w and a kernel K∈Rhk​×wk​, the cross-correlation operation, Y=K⋆X :

​Y∈Rho​×wo​, where ho​=hi​−hk​+1,wo​=wi​−wk​+1Yi,j​=m,n=0∑hk​−1,wk​−1​Km,n​⋅Xi+m,j+n​​​i=0,1,⋯ho​−1j=0,1,⋯wo​−1​​

In Signal Processing terminology, this is valid mode cross-correlation.

2. [Transposed Convolution]
Given a kernel K∈Rhk​×wk​ and G∈Rho​×wo​, the transposed convolution Z=K⋆TG is defined as full mode convolution of G with K:

∴​Z∈Rh×w, where h=ho​+hk​−1,w=wo​+wk​−1Zi,j​=m,n=0∑hk​−1wk​−1​​Km,nrot180​⋅Gi−m,j−n​​​i=0,1,⋯h−1j=0,1,⋯w−1​where, Km,nrot180​=Khk​−1−m,wk​−1−n​≡rot180(K)Gi,j​={Gi,j​0,​0≤i≤hk​−10≤j≤wk​−1​otherwise​≡pad(G;hk​−1,wk​−1)Z=rot180(K)⋆pad(G;hk​−1,wk​−1)​

where G denotes G zero-padded to all indices (i.e. Gp,q​=0 whenever (p,q) falls outside G's domain).

In Signal Processing terminology, this is exactly full mode convolution — equivalently, pad G with hk​−1, wk​−1 zeros on every border and run valid mode cross-correlation with K rotated 180°.

2.1.1 Properties of Base Operations [P-1.1]

1. [Bilinearity of Base Operations]

Given K1​,K2​∈Rhk​×wk​, X∈Rhx​×wx​,

1. [Bilinearity of ⋆]

  1. (αK1​+βK2​)⋆X= α(K1​⋆X)+β(K2​⋆X)
  2. K⋆(αX1​+βX2​)= α(K⋆X1​)+β(K⋆X2​)

2. [Bilinearity of ⋆⊤]

  1. (αK1​+βK2​)⋆⊤X= α(K1​⋆⊤X)+β(K2​⋆⊤X)
  2. K⋆⊤(αX1​+βX2​)= α(K⋆⊤X1​)+β(K⋆⊤X2​)
Proof

1.1 [⋆ linearity in K] Let Y=(αK1​+βK2​)⋆X

Then, by Def. 1.1.1,

∴∴∴​Yi,j​=m,n∑​(α⋅K1m,n​+β⋅K2m,n​)⋅Xi+m,j+n​Yi,j​=m,n∑​α⋅K1m,n​⋅Xi+m,j+n​+β⋅K2m,n​⋅Xi+m,j+n​Yi,j​=α⋅m,n∑​K1m,n​⋅Xi+m,j+n​+β⋅m,n∑​K2m,n​⋅Xi+m,j+n​Y=α(K1​⋆X)+β(K2​⋆X)q.e.d​

1.2 [⋆ linearity in X] Let Y=K⋆(αX1​+βX2​)

Then, by Def. 1.1.1,

∴∴∴​Yi,j​=m,n∑​Km,n​⋅(α⋅X1i+m,j+n​+β⋅X2i+m,j+n​)Yi,j​=m,n∑​α⋅Km,n​⋅X1i+m,j+n​+β⋅Km,n​⋅X2i+m,j+n​Yi,j​=α⋅m,n∑​Km,n​⋅X1i+m,j+n​+β⋅m,n∑​Km,n​⋅X2i+m,j+n​Y=α(K⋆X1​)+β(K⋆X2​)q.e.d​

Proofs of 2.1 & 2.2 come about from Definition 1.1.2, where Y=K⋆⊤X =rot180(K)⋆ pad(X;hk​−1,wk​−1).

Both rotation and pad operator are linear in operands, which when coupled with P-1.1.1.1 proved above, yields the bilinearity of ⋆⊤.

By linear operator, T(α⋅x+β⋅y) =α⋅T(x)+β⋅T(y) is the definition used. q.e.d.

2. [Adjoint Identity]

Given K∈Rhk​×wk​, X∈Rhx​×wx​ and G∈Rhg​×wg​ such that

  • hg​=hx​−hk​+1
  • wg​=wx​−wk​+1

Define ⟨A,B⟩=tr(A⊤B), where A,B∈Rm×n. This is Frobenius inner product.

⟨K⋆X,G⟩=⟨X,K⋆⊤G⟩​

Proof

∴∴∴∴​⟨K⋆X,G⟩=i,j=0∑hg​−1,wg​−1​Gi,j​⋅(K⋆X)i,j​→Definition of Frobenius inner product⟨K⋆X,G⟩=i,j=0∑hg​−1,wg​−1​Gi,j​⋅(m,n=0∑hk​−1,wk​−1​Km,n​⋅Xi+m,j+n​)→Def. 1.1.1, Cross-Correlation⟨K⋆X,G⟩=m,n=0∑hk​−1wk​−1​​i,j=0∑hg​−1wg​−1​​Gi,j​⋅Km,n​⋅Xi+m,j+n​⟨K⋆X,G⟩=m,n=0∑hk​−1wk​−1​​i=mj=n​∑hg​+m−1wg​+n−1​​Gi−m,j−n​⋅Km,n​⋅Xi,j​Define Gi,j​={Gi,j​,0,​0≤i≤hg​−1,0≤j≤wg​−1otherwise​⟨K⋆X,G⟩=m,n=0∑hk​−1wk​−1​​i,j=0∑hg​+hk​−2wg​+wk​−2​​Gi−m,j−n​⋅Km,n​⋅Xi,j​​

The last two steps essentially add zero terms into the mix, since it is evident that the internal summation is being expanded by inserting more indices for which G will have undefined values.

The last two steps:

  1. Defining a G~i,j​ pads hk​−1 zeros on top and bottom borders, wk​−1 zeros on left and right borders, and indices now run from −hk​−1 to hk​+hg​−2 for rows and −wk​−1 to wk​+wg​−2 for columns.

  2. Continuing from step 1, to expand the summation, for any (i−m,j−n) outside index range of G, it will be zero, meaning G~i−m,j−n​⋅Xi,j​ can be added without any consequences.

Hence,

∴​⟨K⋆X,G⟩=i,j=0∑hg​+hk​−2wg​+wk​−2​​Xi,j​m,n=0∑hk​−1wk​−1​​Km,n​⋅G~i−m,j−n​⟨K⋆X,G⟩=tr(X⊤(K⋆⊤G))=⟨X,K⋆⊤G⟩​

q.e.d

3. [Swap Identity]

Given K∈Rhk​×wk​, X∈Rhx​×wx​ and G∈Rhg​×wg​ such that

  • hg​=hx​−hk​+1
  • wg​=wx​−wk​+1

⟨G,K⋆X⟩=⟨G⋆X,K⟩​

Proof

∴∴∴∴∴​⟨K⋆X,G⟩=i,j=0∑hg​−1,wg​−1​Gi,j​⋅(K⋆X)i,j​→Definition of Frobenius inner product⟨K⋆X,G⟩=i,j=0∑hg​−1,wg​−1​Gi,j​⋅(m,n=0∑hk​−1,wk​−1​Km,n​⋅Xi+m,j+n​)→Def. 1.1.1, Cross-Correlation⟨K⋆X,G⟩=m,n=0∑hk​−1wk​−1​​i,j=0∑hg​−1wg​−1​​Gi,j​⋅Km,n​⋅Xi+m,j+n​⟨K⋆X,G⟩=i,j=0∑hg​−1wg​−1​​Km,n​⋅m,n=0∑hk​−1wk​−1​​Gi,j​⋅Xi+m,j+n​⟨K⋆X,G⟩=i,j=0∑hg​−1wg​−1​​Km,n​⋅(G⋆X)m,n​→Def. 1.1.1, cross-correlation⟨K⋆X,G⟩=⟨K,G⋆X⟩​

q.e.d

These two properties will be invaluable for deriving the backprop with ease.

2.2 Conv2D and Conv2DTranspose

There are two layers that come about from this, one used to create smaller images and one for bigger images, the convolution (conv2D) & transposed convolution (conv2Dtranspose) layer. These can collectively be called the convolution layers.

Definition 1.2 [Forward Pass of convolution layers]

1. [Convolution Layer (conv2D)]
The convolution layer (conv2D) takes in a channeled image, X∈Rci​×hi​×wi​, has kernels arranged in a 4D tensor: K∈ Rco​×ci​×hk​×wk​ and biases in a 3D tensor B∈ Rco​×ho​×wo​. The output space Y=Rco​×ho​×wo​ :

​Yi​∈Rho​×wo​,i=0,1,⋯co​−1, where ho​=hi​−hk​+1,wo​=wi​−wk​+1​Y0​=j=0∑ci​−1​K0,j​⋆Xj​+B0​Y1​=j=0∑ci​−1​K1,j​⋆Xj​+B1​⋮Yco​−1​=j=0∑ci​−1​Kc0​−1,j​⋆Xj​+Bco​−1​​​

The last set of equations can be compactly written as:

​Yi​=j=0∑ci​−1​Ki,j​⋆Xj​+Bi​∈Rho​×wo​i=0,1,⋯co​−1​​

2. [Transposed Convolution Layer (Conv2DTranspose)]
The transposed convolution layer takes in a channeled image, X∈Rci​×hi​×wi​, has kernels arranged in a 4D tensor K∈ Rco​×ci​×hk​×wk​ and biases in a 3D tensor B∈Rco​×ho​×wo​. The output space Y=Rco​×ho​×wo​ :

​Yi​∈Rho​×wo​,i=0,1,⋯co​−1, where ho​=hi​+hk​−1,wo​=wi​+wk​−1​Y0​=j=0∑ci​−1​K0,j​⋆TXj​+B0​Y1​=j=0∑ci​−1​K1,j​⋆TXj​+B1​⋮Yco​−1​=j=0∑ci​−1​Kco​−1,j​⋆TXj​+Bco​−1​​​

Compactly:

​Yi​=j=0∑ci​−1​Ki,j​⋆TXj​+Bi​∈Rh×wi=0,1,⋯co​−1​​

PyTorch indexes the filters abit differently, but for consistency, the indexing is used like so over here.

NOTE

1. Notice that this can be written almost like a linear layer.

​Y0​Y1​⋮Yco​−1​​​=​K0,0​K1,0​⋮Kco​−1,0​​K0,1​K1,1​⋮Kco​−1,1​​⋯⋯⋱⋯​K0,ci​−1​K1,ci​−1​⋮Kco​−1,ci​−1​​​⋆​X0​X1​⋮Xci​−1​​​⊕​B0​B1​⋮Bco​−1​​​

In the matrix multiplication, the multiplication is replaced by cross-correlation, the addition is elementwise. All the elements in the matrices and vectors are real matrices.

2. Same trick can be played with transposed convolution

​Y0​Y1​⋮Yco​−1​​​=​K0,0​K1,0​⋮Kco​−1,0​​K0,1​K1,1​⋮Kco​−1,1​​⋯⋯⋱⋯​K0,ci​−1​K1,ci​−1​⋮Kco​−1,ci​−1​​​⋆⊤​X0​X1​⋮Xci​−1​​​⊕​B0​B1​⋮Bco​−1​​​

Where multiplication is replaced with the transposed convolution operation, and addition as usual is elementwise, with elements of matrices and vectors being real matrices.

3. The thing that every lecture on CNN will mention at some point: convolution layer (conv2D) is not convolution, it is cross correlation. But transposed convolution is actual convolution.

2.3 Backward Pass

Theorem 1.1 [Gradients in Base Operations]

1. Let X∈Rhi​×wi​ and K∈Rhk​×wk​, with Y=K⋆X∈Rho​×wo​, dimensions calculated as per Definition 1.1.1. Then, given δY​∈Rho​×wo​, which is δY​≡∂Y∂l​,

​δK​≡∂K∂l​=δY​⋆XδX​≡∂X∂l​=K⋆⊤δY​​​

2. Let X∈Rhi​×wi​ and K∈Rhk​×wk​, with Y=K⋆⊤X∈Rho​×wo​, dimensions calculated as per Definition 1.1.2. Then, given δY​∈Rho​×wo​, which is δY​≡∂Y∂l​,

​δK​≡∂K∂l​=X⋆δY​δX​≡∂X∂l​=K⋆δY​​​

Proof
1. Given Y=K⋆X, with each matrix having the appropriate dimensions,

∴∴∴​dY=K⋆dX+dK⋆X→Easily Verfiabledl=⟨δY​,dY⟩=⟨δY​,K⋆dX+dK⋆X⟩dl=⟨δY​,K⋆dX⟩+⟨δY​,dK⋆X⟩dl=⟨K⋆⊤δY​,dX⟩→P-1.1.2, Adjoint Identity+⟨δY​⋆X,dK⟩→P-1.1.3, Swap Identitydl=⟨δX​,dX⟩+⟨δK​,dK⟩→Total Derivative Theorem​

This gives us:

​δX​=K⋆⊤δY​δK​=δY​⋆X​​

q.e.d

2. Given Y=K⋆⊤X, with each matrix having the appropriate dimensions,

∴∴∴​dY=K⋆⊤dX+dK⋆⊤Xdl=⟨δY​,dY⟩=⟨δY​,K⋆⊤dX⟩+⟨δY​,dK⋆⊤X⟩dl=⟨dX,K⋆δY​⟩+⟨dK⋆δY​,X⟩→P-1.1.2, P-1.1.3dl=⟨dX,K⋆δY​⟩+⟨dK,X⋆δY​⟩​

Hence, by total derivative theorem,

​δK​=X⋆δY​δX​=K⋆δY​​​

q.e.d

Theorem 1.2 [Conv2D & Conv2Dtranspose backpass]

1. Given Conv2D layer, with input expected to be in Rci​×hi​×wi​, and output expected to be in Rco​×ho​×wo​, with kernels in Rco​×ci​×hk​×wk​ and biases in Rco​×ho​×wo​, given the output gradient δY​∈Rco​×ho​×wo​

​δKi,j​=δY,i​⋆Xj​​0≤i≤co​−10≤j≤ci​−1​δB​=δY​δX,j​=i=0∑co​−1​Ki,j​⋆⊤δY,i​0≤j≤ci​−1​​

Very similar to linear layer in some sense.

2. Given Conv2Dtranpose layer, with input expected to be in Rci​×hi​×wi​, and output expected to be in Rco​×ho​×wo​, with kernels in Rco​×ci​×hk​×wk​ and biases in Rco​×ho​×wo​, given the output gradient δY​∈Rco​×ho​×wo​

​δKi,j​=Xj​⋆δY,i​​0≤i≤co​−10≤j≤ci​−1​δB​=δY​δX,j​=i=0∑co​−1​Ki,j​⋆δY,i​0≤j≤ci​−1​​

Proof
1. The forward pass for conv2D can be compactly written as:

∴∴∴∴∴​Yi​=j=0∑ci​−1​Ki,j​⋆Xj​+Bi​0≤i≤co​−1→Def. 1.1.1, conv2D forwarddYi​=j∑​(dKi,j​⋆Xj​+Ki,j​⋆dXj​)+dBj​dl=i∑​tr(δY,i⊤​⋅Yi​)→total derivitive theoremdl=i,j∑​⟨δY,i​,dKi,j​⋆Xj​⟩+⟨δY,i​,Ki,j​⋆dXj​⟩+i∑​⟨δY,i​,dBi​⟩dl=i,j∑​⟨δY,i​⋆Xj​,dKi,j​⟩+⟨Ki,j​⋆⊤δY,i​,dXj​⟩+i∑​⟨δY,i​,dBi​⟩→From Theorem 1.1.1dl=i,j∑​⟨δY,i​⋆Xj​,dKi,j​⟩+j∑​⟨i∑​Ki,j​⋆⊤δY,i​,dXj​⟩+i∑​⟨δY,i​,dBi​⟩→Linearity of inner product​

Using total derivitive theorem, the gradients come out as:

​δKi,j​=δY,i​⋆Xj​​0≤i≤co​−10≤j≤ci​−1​δB​=δY​δX,j​=i=0∑co​−1​Ki,j​⋆⊤δY,i​0≤j≤ci​−1​​

2. The forward pass for conv2Dtranspose is:

∴∴∴∴∴​Yi​=j=0∑ci​−1​Ki,j​⋆⊤Xj​+Bi​0≤i≤co​−1→Def. 1.1.1, conv2Dtranspose forwarddYi​=j∑​(dKi,j​⋆⊤Xj​+Ki,j​⋆⊤dXj​)+dBj​dl=i∑​tr(δY,i⊤​⋅Yi​)→total derivitive theoremdl=i,j∑​⟨δY,i​,dKi,j​⋆⊤Xj​⟩+⟨δY,i​,Ki,j​⋆⊤dXj​⟩+i∑​⟨δY,i​,dBi​⟩dl=i,j∑​⟨Xj​⋆δY,i​,dKi,j​⟩+⟨Ki,j​⋆δY,i​,dXj​⟩+i∑​⟨δY,i​,dBi​⟩→From Theorem 1.1.2dl=i,j∑​⟨Xj​⋆δY.i​,dKi,j​⟩+j∑​⟨i∑​Ki,j​⋆δY,i​,dXj​⟩+i∑​⟨δY,i​,dBi​⟩→Linearity of inner product​

Hence, total derivitive theorem gives you:

​δKi,j​=Xj​⋆δY,i​​0≤i≤co​−10≤j≤ci​−1​δB​=δY​δX,j​=i=0∑co​−1​Ki,j​⋆δY,i​0≤j≤ci​−1​​

q.e.d

2.4 Algorithms for single input

2.4.1 Forward Pass

Algorithm 1.1 [conv2D Single Input Forward Pass (SIFP)]

Input

  • X∈Rci​×hi​×wi​ the input channeled image.

  • conv2D layer parameters

    • K∈Rco​×ci​×hk​×ck​
    • B∈Rco​×ho​×wo​.

Output

  • Y∈Rco​×ho​×wo​, the output of the conv2D forward pass.

Algorithm

  1. for i = 0 to co​−1 do

    1. Yi​←Bi​

    2. for j = 0 to ci​−1 do

      1. Yi​←Yi​+Ki,j​⋆Xj​

    3. end for

  2. end for

  3. return Y

Algorithm 1.2 [conv2Dtranspose Single Input Forward Pass (SIFP)]

Input

  • X∈Rci​×hi​×wi​ the input channeled image.

  • conv2Dtranspose layer parameters

    • K∈Rco​×ci​×hk​×ck​
    • B∈Rco​×ho​×wo​.

Output

  • Y∈Rco​×ho​×wo​, output of the conv2Dtranspose forward pass

  1. for i = 0 to co​−1 do

    1. Yi​←Bi​

    2. for j = 0 to ci​−1 do

      1. Yi​←Yi​+Ki,j​⋆⊤Xj​

    3. end for

  2. end for

Algorithm 1.3 [conv2D Single Input Backward Pass (SIBP)]

Input

  • δY​∈Rco​×ho​×wo​, output gradient

[Cached Inputs]

  • X∈Rci​×hi​×wi​ the input channeled image.

  • conv2D layer parameters

    • K∈Rco​×ci​×hk​×ck​

Output

  • δK​,δB​,δX​ parameter and input gradients of the network.

  2. for j = 0 to ci​−1 do Input gradients

    1. δX,j​←0hi​×wi​​

    3. end for

  3. end for

  4. for i = 0 to co​−1 do Kernel gradients

    1. for j = 0 to ci​−1 do
      1. δK,i,j​←δY,i​⋆Xj​ Theorem 1.2.1
    2. end for

  5. end for

  6. return δK​,δB​,δX​

2.2 Batching in CNN

In the previous section, the unsaid assumption was that the cross-correlation and transposed convolution are efficiently implemented.

But in reality, the naive implementation of those two operations is a dud, since it is not easy to parallelize those two as is.

KEY INSIGHT

Notice that the two operations are actually linear in nature, by virtue of which they can be converted into matrix vector products (MVPs). This is a linear algebra thing now.

So, one route to investigate is: how is this converted into a matrix multiplication which is just beyond awesome since that operation already has efficient hardware to run it along with even more awesome algos to do so, and is it really more efficient to do so?
