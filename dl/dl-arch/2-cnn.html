Convolutional Neural Network (CNN)

This family of Neural Networks are specifically designed to operator on images with channels.

Hence, the input space X= Rci​×hi​×wi​, where i subscript here will stand for input image related attributes.

The output space will depend on the tasks, some common ones being covered in the last section.

The core novelty in this chapter is the convolution layer, which takes in a channeled image and outputs another channeled image, i.e. X= Rci​×hi​×wi​ and Y =Rco​×ho​×wo​ where the o subscript stands for output attributes.

The dual of that is the Transposed convolution Layer which is actually the adjoint operator of the original conv2D operation.

2.1 Building Blocks of CNN

This section deals with convolution layer and its variants. In short, the convolution layer family is an image-to-image type of layer. Hence, X= Rci​×hi​×wi​ and Y =Rco​×ho​×wo​.

2.1 Cross Correlation and Transposed Convolution

Definition 1.1 [Cross-Correlation; Transposed Convolution]

1. [Cross Correlation]
Given an image X∈Rh×w and a kernel K∈Rhk​×wk​, the cross-correlation operation, Y=K⋆X :

​Y∈Rho​×wo​, where ho​=hi​−hk​+1,wo​=wi​−wk​+1Yi,j​=m,n=0∑hk​−1,wk​−1​Km,n​⋅Xi+m,j+n​​​i=0,1,⋯ho​−1j=0,1,⋯wo​−1​​

In Signal Processing terminology, this is valid mode cross-correlation.

2. [Transposed Convolution]
Given a kernel K∈Rhk​×wk​ and G∈Rho​×wo​, the transposed convolution Z=K⋆TG is defined as full mode convolution of G with K:

​Z∈Rh×w, where h=ho​+hk​−1,w=wo​+wk​−1Zi,j​=m,n=0∑hk​−1,wk​−1​Km,n​⋅G~i−m,j−n​​​i=0,1,⋯h−1j=0,1,⋯w−1​​

where G denotes G zero-padded to all indices (i.e. Gp,q​=0 whenever (p,q) falls outside G's domain).

In Signal Processing terminology, this is exactly full mode convolution — equivalently, pad G with hk​−1, wk​−1 zeros on every border and run valid mode cross-correlation with K rotated 180° (Km,n​↦Khk​−1−m,wk​−1−n​).

2.2 Conv2D and Transposed Conv2D Layers

Definition 1.2 [Conv2D Layer; Transposed Conv2D Layer]

1. [Convolution Layer (conv2D)]
The convolution layer (conv2D) takes in a channeled image, X∈Rci​×hi​×wi​, has kernels arranged in a 4D tensor: K∈ Rco​×ci​×hk​×wk​ and biases in a 3D tensor B∈ Rco​×ho​×wo​. The output space Y=Rco​×ho​×wo​ :

​Yi​∈Rho​×wo​,i=0,1,⋯co​−1, where ho​=hi​−hk​+1,wo​=wi​−wk​+1​Y0​=j=0∑ci​−1​K0,j​⋆Xj​+B0​Y1​=j=0∑ci​−1​K1,j​⋆Xj​+B1​⋮Yco​−1​=j=0∑ci​−1​Kc0​−1,j​⋆Xj​+Bco​−1​​​

The last set of equations can be compactly written as:

​Yi​=j=0∑ci​−1​Ki,j​⋆Xj​+Bi​∈Rho​×wo​i=0,1,⋯co​−1​​

2. [Transposed Convolution Layer (ConvTranspose2D)]
The transposed convolution layer takes in a channeled image, X∈Rci​×hi​×wi​, has kernels arranged in a 4D tensor K∈ Rco​×ci​×hk​×wk​ and biases in a 3D tensor B∈Rco​×ho​×wo​. The output space Y=Rco​×ho​×wo​ :

​Yi​∈Rho​×wo​,i=0,1,⋯co​−1, where ho​=hi​+hk​−1,wo​=wi​+wk​−1​Y0​=j=0∑ci​−1​K0,j​⋆TXj​+B0​Y1​=j=0∑ci​−1​K1,j​⋆TXj​+B1​⋮Yco​−1​=j=0∑ci​−1​Kco​−1,j​⋆TXj​+Bco​−1​​​

Compactly:

​Yi​=j=0∑ci​−1​Ki,j​⋆TXj​+Bi​∈Rh×wi=0,1,⋯co​−1​​

NOTE

1. Notice that this can be written almost like a linear layer.

​Y0​Y1​⋮Yco​−1​​​=​K0,0​K1,0​⋮Kco​−1,0​​K0,1​K1,1​⋮Kco​−1,1​​⋯⋯⋱⋯​K0,ci​−1​K1,ci​−1​⋮Kco​−1,ci​−1​​​⋆​X0​X1​⋮Xci​−1​​​⊕​B0​B1​⋮Bco​−1​​​

In the matrix multiplication, the multiplication is replaced by cross-correlation, the addition is elementwise. All the elements in the matrices and vectors are scalar matrices.

2. Same trick can be played with transposed convolution

​Y0​Y1​⋮Yco​−1​​​=​K0,0​K1,0​⋮Kco​−1,0​​K0,1​K1,1​⋮Kco​−1,1​​⋯⋯⋱⋯​K0,ci​−1​K1,ci​−1​⋮Kco​−1,ci​−1​​​⋆⊤​X0​X1​⋮Xci​−1​​​⊕​B0​B1​⋮Bco​−1​​​

Where multiplication is replaced with the transposed convolution operation, and addition as usual is elementwise.
